# Arabian Rangers Tourism

Website for Arabian Rangers Tourism — desert safaris, city tours, buggy rides and UAE adventures.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
